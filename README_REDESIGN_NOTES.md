# ملاحظات تحديث صفحات الهبوط

تم تحديث الصفحات السبع: `index.html` و`criminal.html` و`family.html` و`commercial.html` و`labor.html` و`realestate.html` و`notary.html`.

أُضيفت طبقة مشتركة للحركة والواجهة تشمل ظهوراً سلساً لعناصر الصفحة عند التمرير، تأثيرات hover للبطاقات والأزرار، عزل اتجاه أرقام الهاتف داخل صفحات RTL، واحترام إعدادات `prefers-reduced-motion`.

تم الحفاظ على Google Tag Manager بالمعرّف `GTM-KKHH6SBP`، وأرقام الهاتف وروابط واتساب الأصلية، والشعار `logo-main.png`، وبنية النوافذ المنبثقة ووظائف التتبع الحالية. تم فحص الروابط الداخلية وعدم وجود ملفات HTML مفقودة، ثم تم رفع التعديل إلى فرع `main` في GitHub ضمن الالتزام `2c0ed6d`.
